# Редагування квестів

Запустіть `EDIT_CONTENT.bat`. Перша вкладка — **Квести**.

Ліворуч є довідник із 15 типів звичайних контрактів, 6 сюжетних/автоматичних
типів та список створених авторських квестів. Виберіть звичайний тип і натисніть
**Новий квест** або виберіть наявний квест для редагування. Доступні також
дублювання, пошук, вимкнення та видалення.

Для окремого квесту задайте назву, опис, тип, гроші й досвід за виконання.
Для полювання/трофеїв можна змінити кількість цілей; для постачання — кількість
їжі й аптечок. Решта типів використовують свої звичайні ігрові механіки:
доставка, мініігри, пошук, видане спорядження тощо.

## Умови появи

Усі умови мають виконуватися одночасно:

- Діапазон рівня героя.
- Діапазон репутації в місті квестодавця.
- Найраніший хід гри.
- ID міст через кому (нумерація від 0; порожнє поле — всі міста з мером).
- ID завершених попередніх авторських квестів через кому.
- Перемикач «Увімкнено».

Квести з’являються у пропозиціях мера з урахуванням загального ліміту активних
квестів і доступних пропозицій. Авторські пропозиції йдуть перед звичайними.
Для доставки потрібен доступний одержувач, для інших спеціалізованих типів —
відповідні передумови й придатна місцевість. У містах без мера та у мандрівного
писаря авторські контракти не видаються.

Одноразовий квест не повертається після здачі або скасування. Для повторюваного
задайте паузу в ходах після здачі/скасування. Поки квест активний, інша копія
не з’явиться в жодному місті. Залежності не можуть утворювати цикл.

Сюжетні типи (поселення спеціалістів, дозвіл кордону, подяка, метро) показані
як довідка: їх продовжує створювати відповідний сюжетний механізм.

## Збереження

Натисніть **Зберегти всі зміни** або Ctrl+S і перезапустіть гру.
Визначення зберігаються в `data/quests.json` разом з іншими змінами редактора;
попередня версія — у `data/quests.json.bak`. Помилка запису відкочує весь набір
змін. Уже прийняті квести залишаються в сейві зі своїми попередніми нагородами
й описом. ID квесту сталий; для іншого ID використовуйте дублювання.
