# Гексагональна світова мапа

Рендерер залишається Tkinter. Arcade у цій гілці не використовується.
Для масштабування та масок арту потрібен Pillow: `python -m pip install -r requirements-game.txt`.

Світ має шестикутні клітинки з вершиною вгорі. Непарні ряди зміщені праворуч.
Збережено масив world[y][x], координати міст, квестів, сховків і гравця у старих
сейвах. Старі збереження не перезаписуються під час завантаження. Старий дробовий
залишок довжини діагонального руху обнуляється в пам'яті: тепер кожен гекс — один хід.

- Клік по гексу будує маршрут із шести напрямків, враховуючи воду, скелі та паркан.
- Q/W: вгору ліворуч / праворуч; A/D: ліворуч / праворуч; Z/X: вниз ліворуч / праворуч.
- Стрілки теж доступні: вгору → північний схід, вниз → південний схід; S → південний захід.
- E лишається взаємодією. Пробіл зупиняє/продовжує маршрут. Shift+M відкриває атлас.
- Арена використовує попередню незалежну геометрію `hexgrid.py` та попереднє керування.

`world_hex.py` задає сусідство, відстань, проєкцію, грані та вибір клітинки мишею.
`world_map.py` малює світ, атлас, дороги, радіацію, паркан, метро, квестові області та маркери.
`world_hex_art.py` читає assets/hex/terrain_hex_v01.png і нормалізує нерівні клітинки
чернетки в пам'яті, використовуючи спільну маску. Окремих радіаційних тайлів немає.

Дорожні сполучення будуються по центрах спільних граней; усі 64 комбінації шести
сусідів підтримуються без додаткових зображень. Початкові дороги та координати
міст залишаються зв'язними: попередні горизонтальні/вертикальні переходи також
є гранями нової сітки. Форми біомів та розкладка світу не перегенеровуються при завантаженні.

Це перша інтеграція. Арт ще не має узгоджених безшовних переходів усіх біомів;
їх можна доробляти незалежно від правил пересування. Перевірка:
`python -m unittest test_world_hex test_diagonal test_journey test_border`.
Візуальна перевірка без запису сейву: `python tools/check_world_hex_ui.py`.

  координати та властивості. Повернення з бою відновлює фон автоматично.
